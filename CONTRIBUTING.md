If you've found a bug, please submit a normal bug report. You can attach a patch file if you want to provide a suggestion for a fix. If the bug was found through fuzzing, please upload the sample file as a normal attachment. Do not ever attach a Python script or hash.

I'm not accepting large pull requests, regardless of whether or not it's written by a human or AI. If you have a bug fix, either keep the change small and focused, or just create a normal bug report with a brief description. Do not create a new test program thinking you're being helpful, because you're not. All you're doing is added junk to the code base.

Do not use AI to generate the issue description. I prefer interacting with humans and I do not like excessive detail and verbiage.

If you want to contribute to this project in some way other than bug fixing then talk to me about it first, preferably on Discord. This project is focused on what I need personally so it's unlikely I'll have any interest in contributions other than bug fixes.
